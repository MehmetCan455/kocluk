# YKS Takip

YKS hazırlığı için yerel çalışan (local-first) bir takip uygulaması. Veriler tarayıcıda saklanır; hesap, senkronizasyon veya ağ bağlantısı gerektirmez.

## Kurulum

```bash
npm install
```

## Komutlar

```bash
npm run dev        # geliştirme sunucusu
npm run build      # tip kontrolü + üretim derlemesi
npm test           # testler
npm run typecheck  # yalnızca tip kontrolü
```

> Yayınlama (deployment) ayrıntıları sonraki bir görevde eklenecek.
